# Bank Branch Performance Analysis

Internship project — **Banque de Tunisie**.

## Goal
Compare the performance of the bank's branches over several years to support management decisions.

## What the notebook covers
- Selection and cleaning of the relevant indicators
- Year-by-year comparison of branch results
- Average interest rates by year
- Evolution of credit volumes and credit types over time

## Run it
```bash
pip install pandas numpy matplotlib seaborn
jupyter notebook bank_branch_performance_analysis.ipynb
```

The notebook is in French. The source data is internal to the bank and is not included.

**Stack:** Python · pandas · Matplotlib · Seaborn
