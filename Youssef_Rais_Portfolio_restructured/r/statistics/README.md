# Statistics in R

Coursework notebooks on inferential statistics, written with the R kernel for Jupyter.

| Notebook | Content |
|---|---|
| `intro_to_r.ipynb` | Introduction to R: descriptive statistics (`summary`, `str`) and visualisation (histograms, bar plots) on built-in datasets |
| `best_estimator.ipynb` | Discrete uniform distribution: derives the maximum likelihood estimator, then compares estimators by bias and variance through simulation |
| `hypothesis_testing.ipynb` | Hypothesis testing: null and alternative hypotheses, rejection region, p-value, normality check with a Q-Q plot |

Notebooks are in French.

**Run:** requires Jupyter with the [IRkernel](https://irkernel.github.io/).
