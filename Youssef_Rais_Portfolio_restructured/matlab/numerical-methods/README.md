# Numerical Methods in MATLAB

Three numerical analysis projects, each with source code and a written report (in French).

| Project | Methods | Folder |
|---|---|---|
| Root finding for non-linear equations | Bisection, Newton's method | [`root-finding/`](root-finding) |
| Numerical integration | Composite trapezoidal and Simpson rules, error analysis | [`numerical-integration/`](numerical-integration) |
| Ordinary differential equations | Explicit Euler, Runge–Kutta 2 and 4 | [`ode-solvers/`](ode-solvers) |

Each folder contains:
- `src/`: MATLAB functions and exercise scripts
- `report.pdf`: project report with results and convergence analysis

**Run:** open the folder in MATLAB (or GNU Octave) and run the exercise scripts in `src/`.
